# 设计决策：为什么从系统接口出发

## 核心判断

本项目选择“传感器—接口—数据—验证”作为主线，而不是从一张完整芯片框图或一组漂亮指标开始。原因是气敏系统的主要不确定性跨越材料、接触、环境、模拟电路、校准和封装，任何单层优化都可能被另一层覆盖。

## 关键决策

### 1. 先定义测量对象，再选择AFE

电阻、电容、电化学电流和场效应参数变化需要不同偏置与前端。机制不明确时冻结电路，会把未确认的材料假设固化为芯片成本。

### 2. 把Touch IC当作方法来源，不当作现成电路

可迁移的是多通道扫描、公共资源复用、数字控制模拟、校准和测试思维；不可直接迁移的是输入量、工作点、带宽、噪声模型与器件接口。

### 3. 把阵列价值定义为“可比较的信息”

仅增加通道数不等于增加信息。阵列必须具有同步条件、偏置记录、校准状态和失败归因，数据才可以用于后续分析。

### 4. 将成本拆成完整系统树

任何成本比较至少需要同时包含硅面积、良率、封装、测试、PCB、外围器件、装联、功耗和校准。单独比较晶圆价格不能证明系统优势。

### 5. 将数字控制模拟画成闭环

数字系统不仅接收ADC结果，还可以控制通道、量程、激励、采样窗口和校准动作。闭环方向必须同时表达控制和反馈，避免把系统误画成单向流水线。

### 6. 先验证少量通道，再讨论规模化

第一阶段应回答“能否测对、能否区分误差、是否值得扩展”，而不是提前承诺完整产品。扩大规模必须由前一级证据触发。

## 当前不做的决定

- 不冻结具体AFE拓扑和性能指标；
- 不承诺某一种敏感材料能够长期常温工作；
- 不把邻近论文结果外推为本项目结果；
- 不公开潜在专利的实现细节、尺寸、时序或权利要求组合；
- 不根据概念成本模型给出确定市场规模。

这些边界让公开讨论聚焦于研究问题，同时为后续实验和知识产权工作保留空间。
