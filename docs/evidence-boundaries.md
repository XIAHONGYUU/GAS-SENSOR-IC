# 技术主张与证据边界

## 状态定义

- **来源事实**：能够定位到公开论文、官方资料或可复现实验。
- **作者推导**：由已有事实推演出的架构判断，必须说明成立条件。
- **研究假设**：值得验证但尚无充分证据的路线。
- **排除表述**：证据不足、可能泄露或容易造成误导，不进入公开结论。

## 主张表

| 主张 | 当前性质 | 公开表述边界 |
|---|---|---|
| 气敏器件需要偏置、模拟调理、转换和数据记录 | 系统抽象 | 可作为问题框架，不代表行业方案唯一 |
| Touch IC与气敏读出共享多通道采集方法 | 作者推导 | 只说方法可借鉴，不说电路可直接复用 |
| 集成可能降低面积和重复BOM | 研究假设 | 必须保留良率、封装、测试和产量条件 |
| 常温路线可能降低持续加热相关负担 | 条件性推导 | 前提是响应、恢复和长期稳定性可重复 |
| 校准可以改善一致性与可追溯性 | 作者推导 | 不声称校准能解决不可逆材料变化 |
| 主动扫描可能增加可辨识信息 | 研究假设 | 必须定义激励、观测量、窗口和对照实验 |
| 标准CMOS可与敏感材料后处理结合 | 研究假设 | 邻近论文不是本项目工艺可行性的证明 |
| 成本下降可能扩大可达应用 | 商业假设 | 不使用确定销量或指数增长表述 |

## 论文证据卡

### Berkeley / Science Advances 2026

- 器件：功能化CNT-FET阵列。
- 实际测量：固定栅压和源漏偏置下的电流时间序列。
- 支持：常温异质阵列、材料后处理、多通道响应和分类任务。
- 不支持：本项目AFE已经成立、所有响应均由场效应产生、普通CMOS量产成本已经验证。
- DOI：`10.1126/sciadv.aec7965`。

### MIT / Nature Sensors 2026

- 器件：功能化CNFET集成系统。
- 实际测量：固定工作点响应、栅压扫描、转移特性及对照结构。
- 支持：栅压工作点和跨导可参与响应增强，集成阵列具有工程先例。
- 不支持：经典敏感栅硅MOSFET机理、本文提出的CMOS后处理或AFE已被验证。
- DOI：`10.1038/s44460-026-00037-z`。

## 数据与成本规则

进入公开结论的数字必须同时记录：来源、日期、器件或工艺条件、批量、测量方法和适用范围。缺少这些字段的晶圆价格、BOM、功耗、市场规模和性能指标，只能作为情景输入，不作为事实。

## 更新规则

当新实验或一级来源出现时，先更新证据卡，再修改报告结论。不得为了保持既有架构而降低反证的优先级。
