# 常温气敏传感器阵列读出芯片：公开讨论摘要

状态：公开讨论稿。本文整理自多轮项目讨论，保留核心思想，删除个人履历、企业评价、未经证实的市场数字和潜在专利实施细节。

## 1. 问题定义

气敏研究通常以材料灵敏度、选择性、响应和恢复为中心，但当系统需要从单个器件扩展到阵列、长期运行和批量应用时，还会遇到另一组问题：

- 多个器件的输出范围和偏置是否能够由统一接口覆盖；
- 噪声、漂移、接触变化和环境变化能否被区分；
- 多通道数据是否具有一致的时间基准和可追溯条件；
- 校准、测试、通信和数据组织是否可以形成闭环；
- 板级方案的面积、功耗、装联和重复模块是否限制阵列扩展。

本项目的研究对象不是某一种敏感材料，而是材料与数字系统之间的接口层。

## 2. 核心思想

设想采用成熟 CMOS 工艺，把多通道模拟调理、通道选择、模数转换、校准、时序控制和接口通信组织为一套可验证的数模混合系统。敏感材料及其后处理属于独立层，必须与硅片工艺、封装和测试边界分别讨论。

概念链路为：

```text
气敏材料或器件
→ 偏置与模拟检测
→ 多通道选择和同步采样
→ 模数转换
→ 基线、校准与状态记录
→ 数据接口与系统验证
```

这是一项研究假设，而不是已经冻结的产品规格。

## 3. 三条价值假设

### 成本

芯片集成可能通过共享ADC、参考、时钟、控制和通信模块，减少板级重复器件、装联和人工校准。但真实交叉点取决于die面积、良率、封装、测试、PCB、BOM和产量，不能只用晶圆价格证明。

### 空间与应用门槛

板级通道增加通常伴随器件、走线、连接和供电增长。芯片级实现可能降低体积和安装门槛，从而进入原本难以容纳分立系统的场景。市场扩展是待验证的商业假设，不预设指数增长。

### 阵列与信息量

阵列价值不仅来自通道数量，还来自同步采样、可控激励、差分观测、校准状态和实验条件记录。更多数据只有在可比较、可重复和可归因时才构成更多信息。

## 4. 与Touch IC方法的关系

Touch IC提供的是方法参考：多通道寻址、微弱变化检测、公共模拟资源复用、数字控制模拟、基线处理和量产测试。气敏器件与触摸面板在传感量、带宽、偏置、噪声、漂移和环境依赖上均不同，因此不能直接复用电路或指标。

正确表述是“迁移系统方法并重新验证”，不是“把触摸芯片改名即可使用”。

## 5. 当前技术分叉

不同传感机制对应不同AFE：

- 电阻或电导变化：关注宽动态范围、偏置、低频噪声、接触电阻和恢复；
- 功能化FET：关注栅压工作点、跨导、阈值、接触势垒与复合沟道贡献；
- 电容或介电变化：关注寄生电容、激励方式、差分结构和湿度共模；
- 电化学电流：关注恒电位条件、输入电流范围和传感器寿命。

机制未确定之前，不应提前冻结AFE拓扑。

## 6. 优先回答的公开问题

1. 目标器件在真实环境下的输出范围、漂移和可逆性是什么？
2. 哪些变化来自材料，哪些来自接触、偏置、温湿度或测量系统？
3. 多通道主动扫描相较静态采样增加了什么可辨识信息？
4. 芯片校准能补偿哪些误差，哪些材料不可逆性无法由算法消除？
5. 标准CMOS、敏感材料后处理、封装和测试之间的责任边界是什么？
6. 何种规模下芯片级系统相对板级方案出现可验证优势？
